# 补码加减法运算模拟器 (Twos Complement Simulator)

## 📖 项目简介
本项目是计算机导论课程的综合实验，旨在通过可视化界面的方式，分步演示 8 位/16 位整数的原码、反码、补码转换，以及补码加减法运算过程、进位产生与溢出判断。

## 🚀 安装与运行步骤
1. 确保您的电脑已安装 Python 3.8 或更高版本。
2. 将仓库代码下载到本地。
3. 在终端运行：`python src/main.py`
